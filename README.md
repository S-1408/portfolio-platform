# Portfolio Platform

A Turborepo and pnpm workspace for a Next.js Multi-Zones portfolio platform.

## Requirements

- Node.js 24 LTS (see `.nvmrc`)
- pnpm 11.5.1

## Getting started

```sh
pnpm install
pnpm dev
```

The portfolio app runs at [http://localhost:3000](http://localhost:3000).

## Workspace commands

```sh
pnpm dev
pnpm build
pnpm lint
pnpm typecheck
pnpm test
pnpm format
```

See [CLAUDE.md](./CLAUDE.md) for the architecture and contribution rules.
